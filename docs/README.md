## 🎯 الاتجاه المعتمد

**① Vibrant Premium — تنفيذ زجاجي فاخر:** شبابي واحترافي وفخم (ليس طفولياً)،
أيقونات SVG راقية بدل الإيموجي، glassmorphism قوي، وأنيميشن «واو» خفيف على الأداء.

- **الألوان:** كحلي `#16264b` + ذهبي `#af9136` + نبضات بنفسجي `#7C6CFC` / تركوازي `#10B4A0` / مرجاني `#FF7A59`.
- **الذهبي كنص على خلفية فاتحة** يَغمَق إلى `#8A7028` للتباين (أداة `.text-gold-ink`).
- **وضع ليلي ونهاري** عبر رموز CSS متغيّرة في `@theme`. عربي RTL هو التجربة الأساسية.
